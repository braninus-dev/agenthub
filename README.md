# AgentHub: Universal Multi-Agent Orchestrator & Bionic Live HUD

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](https://opensource.org/licenses/MIT)
[![PRs Welcome](https://img.shields.io/badge/PRs-welcome-brightgreen.svg)](http://makeapullrequest.com)

**AgentHub** is a zero-dependency, plug-and-play multi-agent orchestration framework and cyberpunk bionic live dashboard designed for developers using **Claude Code, OpenAI Codex, Hermes Agent, and Cursor**.

---

## 🌟 Key Features

1. **Decoupled Architecture (UAP Protocol)**:
   - Connect any master agent (Claude Code / Codex / Hermes / WorkBuddy) with any worker agents.
   - Zero heavyweight dependencies: operates entirely via lightweight event-driven JSON and file queues.
2. **Bionic Neural Synapse HUD (Live Dashboard)**:
   - High-performance 2D Canvas particle physics with dynamic Bézier photon trails.
   - Real-time impact shockwave feedback upon task receipt.
   - Compact 2x3 cellular bionic card design (< 0.3% CPU usage).
3. **Hardware & Rate-Limit Guardians**:
   - Built-in multi-tier memory/CPU overload throttle and rate-limit guard.

---

## 🚀 Quick Start

### 1. Launch the Live HUD
Open `web/index.html` in your browser:
```bash
open web/index.html
```

### 2. Emit an Event from your Agent
Dispatch a task from any CLI or script:
```bash
python3 skill/scripts/dispatch_event.py TASK_DISPATCH hermes zcode clean_text RUNNING
```
Watch the high-energy photon stream across your screen into the target worker card in real time!
