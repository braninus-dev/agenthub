# Universal Agent Orchestrator & Live HUD

A unified, event-driven multi-agent orchestration system that fuses intelligent task dispatching with real-time visual photon HUD feedback.

## Key Capabilities
1. **Intelligent Decomposition & Dispatching**: Main brain (Hermes / Claude / Codex) decomposes tasks and routes sub-tasks to specialized workers.
2. **Real-Time Bionic Photon HUD**: Live event stream renders neural synapses, particle beams, and node impacts with <30ms latency.
3. **Universal Agent Protocol (UAP)**: Decoupled file-based and IPC event bus (`agent-events.json` + `agent-metrics-live.json`).
